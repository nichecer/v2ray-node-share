## 关于可用性

本项目对节点进行基本格式检查和完全相同条目的去重，未进行连通性测试、速度测试或安全性验证。
免费节点状态可能变化，订阅成功不代表节点一定可连接。遇到失效，可以更新订阅或切换其他节点。

抓取失败或没有有效节点时保留上次成功内容，以上时间代表最近成功整理时间。
